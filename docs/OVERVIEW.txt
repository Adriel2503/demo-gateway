================================================================================
                          ENDPOINTS
================================================================================

GET /webhook
  → Verificación de Meta (handshake)
  Parámetros: hub_mode, hub_verify_token, hub_challenge
  Respuesta: Devuelve el challenge

POST /webhook
  → Recepción de mensajes
  Body: Payload JSON de Meta
  Respuesta: {"success": true, "messages_processed": 1}

GET /health
  → Health check del servicio
  Respuesta: {"status": "ok", "service": "WhatsApp Gateway", ...}

OPTIONS /webhook
  → CORS preflight
  Respuesta: 200 OK

GET /docs
  → Documentación interactiva Swagger
  URL: http://localhost:8000/docs

GET /redoc
  → Documentación ReDoc
  URL: http://localhost:8000/redoc


================================================================================
                          CONFIGURACIÓN
================================================================================

Variables de entorno (.env):

VERIFY_TOKEN
  └─ Token para verificación de Meta
     Ejemplo: bb16916dccfa54d8ee964f2546b31cb112dec84d60b3aba0aa5201bcf5a0b89c

WHATSAPP_TOKEN
  └─ Token de acceso a WhatsApp API de Meta
     Obtener en: https://developers.facebook.com/apps

APP_SECRET
  └─ Secret para validar firma de webhooks
     Obtener en: https://developers.facebook.com/apps/settings/basic

AGENT_SERVICE_URL
  └─ URL donde procesar mensajes
     Ejemplos:
     - http://localhost:8001/process (desarrollo)
     - https://n8n.dominio.com/webhook (N8N)
     - https://agente-service.com/process (Agent Service)

PORT
  └─ Puerto de escucha (default: 8000)

HOST
  └─ Host de escucha (default: 0.0.0.0)


================================================================================
                          CAMBIAR SERVICIO
================================================================================

Para cambiar a dónde enviar los mensajes:

1. Editar archivo .env:
   AGENT_SERVICE_URL=https://nueva-url.com/webhook

2. Reiniciar el servicio:
   Ctrl+C
   python main.py

¡Listo! Ya está enviando a la nueva URL.
