FLUJO DE REQUEST A RESPONSE
================================================================================

  Client (Agent Service, Browser, etc)
              |
              | POST /send {payload}
              v
        main.py::send_message()
              |
              +-- Instancia SendWhatsAppService
              |
              v
    send_service.py::process()
              |
              +-- Valida con SendPayload.validate()
              |       |
              |       v
              |   message_types.py::SendPayload
              |
              +-- Extrae datos
              |
              +-- Formatea número telefónico
              |       |
              |       v
              |   formatters.py::format_phone_number()
              |
              +-- Selecciona tipo (text, image, etc)
              |
              +-- Envía según tipo
              |       |
              |       v
              |   meta_client.py::MetaWhatsAppClient
              |       - send_text()
              |       - send_image()
              |       - send_document()
              |       - send_audio()
              |       - send_video()
              |
              +-- Procesa respuesta de Meta
              |       |
              |       v
              |   formatters.py::format_response_*()
              |
              v
    Response estructurada {success, message, data}
              |
              v
          Client

│   • Manejar requests/responses                                         │

│                                                                         │

│ Independencia:                                                          │

│   • Puede usarse en CLI, workers, tests, etc.                          │

│ Clase: MetaWhatsAppClient                                              │
│                                                                         │
│ Responsabilidades:                                                      │

│   send_document()    - Envía documento (con filename y caption)        │

│   send_video()       - Envía video (con caption opcional)              │

┌─────────────────────────────────────────────────────────────────────────┐
│ formatters.py (Utilidades de Formateo)             ~120 líneas         │
├─────────────────────────────────────────────────────────────────────────┤
│ Responsabilidades:                                                      │
│   • Formatear números telefónicos                                      │
│   • Estructurar respuestas exitosas                                    │
│   • Estructurar respuestas de error                                    │
│                                                                         │
│ Funciones:                                                              │
│   format_phone_number()    - Normaliza números (agregar código país)   │
│   format_response_success() - Estructura respuesta OK                   │
│   format_response_error()   - Estructura respuesta error                │
│                                                                         │
│ Logica de format_phone_number():                                        │
│   1. Elimina espacios, guiones, paréntesis, +                          │
│   2. Si empieza con 0, lo quita (formato peruano)                      │
│   3. Si no tiene código de país, agrega '51' (Perú)                    │
│                                                                         │
│ Ejemplos:                                                               │
│   '980253258'          → '51980253258'                                 │
│   '+51 9 8025 3258'    → '51980253258'                                 │
│   '09 8025 3258'       → '51980253258'                                 │
│                                                                         │
│ Independencia:                                                          │
│   • Agnóstico del dominio (solo formatos)                              │
│   • Reutilizable en cualquier contexto                                 │
└─────────────────────────────────────────────────────────────────────────┘

================================================================================
VENTAJAS DE ESTA ARQUITECTURA
================================================================================

✓ SEPARACIÓN DE RESPONSABILIDADES
  - Cada módulo tiene un propósito claro
  - Fácil de entender y mantener
  - Cambios localizados

✓ REUTILIZABLE
  - meta_client.py puede usarse en otros proyectos
  - formatters.py es agnóstico del dominio
  - message_types.py es independiente de FastAPI
  - send_service.py puede usarse en CLI, workers, etc.

✓ TESTEABLE
  - Cada módulo puede testearse aisladamente
  - Mocks fáciles de crear
  - No hay dependencias circulares

✓ ESCALABLE
  - Agregar nuevo tipo de mensaje = 5 cambios simples
  - Cambiar API de Meta = cambios solo en meta_client.py
  - Agregar queue (Redis) = cambios solo en main.py

✓ DOCUMENTADO
  - Cada función tiene docstring
  - Type hints completos
  - Ejemplos de uso incluidos

✓ NO SATURADO
  - main.py: 100 líneas (clean and focused)
  - Cada módulo: 120-250 líneas (mantenible)
  - Total: ~1000 líneas bien organizadas

EJEMPLO: AGREGAR NUEVO TIPO DE MENSAJE (Location)
================================================================================

1. Agregar enum a message_types.py:
   class MessageType(str, Enum):
       LOCATION = 'location'

2. Agregar validación a SendPayload:
   def _validate_location(self) -> bool:
       if not self.get('latitude') or not self.get('longitude'):
           self.errors.append('Requerido: latitude, longitude')
           return False
       return True

3. Agregar getter a SendPayload:
   def get_location(self) -> tuple:
       return (self.get('latitude'), self.get('longitude'))

4. Agregar método a MetaWhatsAppClient:
   async def send_location(self, phone_number_id, to, lat, lon, name=None):
       payload = {
           'messaging_product': 'whatsapp',
           'to': to,
           'type': 'location',
           'location': {'latitude': lat, 'longitude': lon, 'name': name}
       }
       return await self._send_request(phone_number_id, payload)

5. Agregar caso a SendWhatsAppService._send_by_type():
   elif message_type == MessageType.LOCATION:
       lat, lon = send_payload.get_location()
       return await self.meta_client.send_location(...)

6. Listo! Sin modificar main.py
